# DompetKu

DompetKu adalah aplikasi pencatat keuangan pribadi yang membantu Anda mencatat pemasukan, pengeluaran, dan transfer antar-dompet. Antarmukanya dirancang agar nyaman digunakan di ponsel maupun komputer.

Laporan mingguan, bulanan, dan tahunan merangkum arus kas serta pengeluaran berdasarkan transaksi yang dicatat.

## Fitur

- Pencatatan transaksi dan pengelolaan beberapa dompet.
- Kategori untuk membantu mengelompokkan transaksi.
- Laporan keuangan berkala dalam tampilan bergaya struk digital.
- Mode tamu dengan penyimpanan lokal dan opsi sinkronisasi akun.
